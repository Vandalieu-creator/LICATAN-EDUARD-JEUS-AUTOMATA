EXAMPLE 1: DFA MINIMIZATION
============================

CONNECTION TO PREVIOUS ACTIVITY
This DFA is connected to the previous C-style comment activity.
The language starts with "/*" and accepts a comment when it properly
ends with "*/". This example demonstrates DFA minimization by adding
a state (q5) that has the same behavior as q2. The two equivalent
states can therefore be combined.

ORIGINAL DFA
------------

States (Q):
{q0, q1, q2, q3, q4, q5, qtrap}

Alphabet (Σ):
{/, *, a}

Start State:
q0

Accepting State:
{q4}

Transition Table:

| State   | /      | *      | a      |
|---------|--------|--------|--------|
| -> q0   | q1     | qtrap  | qtrap  |
| q1      | qtrap  | q2     | qtrap  |
| q2      | q2     | q3     | q2     |
| q3      | q4     | q3     | q5     |
| *q4     | qtrap  | qtrap  | qtrap  |
| q5      | q2     | q3     | q2     |
| qtrap   | qtrap  | qtrap  | qtrap  |

MINIMIZATION
------------

P0:
{{q4}, {q0, q1, q2, q3, q5, qtrap}}

P1:
{{q4}, {q0, q1, qtrap}, {q2, q5}, {q3}}

P2:
{{q4}, {q0, qtrap}, {q1}, {q2, q5}, {q3}}

P3:
{{q4}, {q0}, {qtrap}, {q1}, {q2, q5}, {q3}}

P4:
{{q4}, {q0}, {qtrap}, {q1}, {q2, q5}, {q3}}

Since P3 = P4, the partitioning stops.

Equivalent states:
q2 and q5

Therefore:
q2 ≡ q5

They can be combined into:
q25

MINIMIZED DFA
-------------

States:
{q0, q1, q25, q3, q4, qtrap}

Start State:
q0

Accepting State:
{q4}

Minimized Transition Table:

| State   | /      | *      | a      |
|---------|--------|--------|--------|
| -> q0   | q1     | qtrap  | qtrap  |
| q1      | qtrap  | q25    | qtrap  |
| q25     | q25    | q3     | q25    |
| q3      | q4     | q3     | q25    |
| *q4     | qtrap  | qtrap  | qtrap  |
| qtrap   | qtrap  | qtrap  | qtrap  |

EXAMPLE INPUTS
--------------

1. /*a*/       -> ACCEPT
2. /**/        -> ACCEPT
3. /***/       -> ACCEPT
4. /*a*a*/     -> ACCEPT
5. /*a/a*/     -> ACCEPT
6. /**         -> REJECT
7. /*/         -> REJECT
8. /**/a       -> REJECT
9. //aaaa      -> REJECT

CONCLUSION
----------

The DFA was minimized by identifying equivalent states. States q2 and
q5 have identical transitions for every input symbol, so they were
combined into q25. The minimized DFA recognizes the same language as
the original DFA while using fewer states.
