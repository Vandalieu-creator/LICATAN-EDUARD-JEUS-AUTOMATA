EXAMPLE 2: DFA MINIMIZATION
============================

CONNECTION TO PREVIOUS ACTIVITY
This example is also related to the previous C-style comment activity.
Instead of recognizing a block comment such as /*a*/, this DFA
recognizes a simple line-comment pattern that starts with "//" and
contains one or more "a" characters.

ORIGINAL DFA
------------

States (Q):
{q0, q1, q2, q3, q4, qtrap}

Alphabet (Σ):
{/, *, a}

Start State:
q0

Accepting States:
{q3, q4}

Transition Table:

| State   | /      | *      | a      |
|---------|--------|--------|--------|
| -> q0   | q1     | qtrap  | qtrap  |
| q1      | q2     | qtrap  | qtrap  |
| q2      | qtrap  | qtrap  | q3     |
| *q3     | qtrap  | qtrap  | q4     |
| *q4     | qtrap  | qtrap  | q4     |
| qtrap   | qtrap  | qtrap  | qtrap  |

MINIMIZATION
------------

P0:
{{q3, q4}, {q0, q1, q2, qtrap}}

P1:
{{q3, q4}, {q0, q1, qtrap}, {q2}}

P2:
{{q3, q4}, {q0, qtrap}, {q1}, {q2}}

P3:
{{q3, q4}, {q0}, {qtrap}, {q1}, {q2}}

P4:
{{q3, q4}, {q0}, {qtrap}, {q1}, {q2}}

Since P3 = P4, the partitioning stops.

Equivalent states:
q3 and q4

Therefore:
q3 ≡ q4

They can be combined into:
q34

MINIMIZED DFA
-------------

States:
{q0, q1, q2, q34, qtrap}

Start State:
q0

Accepting State:
{q34}

Minimized Transition Table:

| State   | /      | *      | a      |
|---------|--------|--------|--------|
| -> q0   | q1     | qtrap  | qtrap  |
| q1      | q2     | qtrap  | qtrap  |
| q2      | qtrap  | qtrap  | q34    |
| *q34    | qtrap  | qtrap  | q34    |
| qtrap   | qtrap  | qtrap  | qtrap  |

EXAMPLE INPUTS
--------------

1. //a        -> ACCEPT
2. //aa       -> ACCEPT
3. //aaa      -> ACCEPT
4. //aaaa     -> ACCEPT
5. //         -> REJECT
6. /          -> REJECT
7. /*a*/      -> REJECT
8. //a/       -> REJECT
9. ///a       -> REJECT

CONCLUSION
----------

The DFA was minimized by identifying equivalent accepting states.
States q3 and q4 have the same behavior and are therefore equivalent.
They were combined into q34. The resulting minimized DFA recognizes
the same language using fewer states.
